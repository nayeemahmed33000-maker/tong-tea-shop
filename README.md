# Tong Tea Shop — টং — চা ও আড্ডার ঠিকানা

The exact Tong tea-shop website (26-item menu, location, phone, Facebook link),
as it runs live at https://tong-pages.pages.dev.

- **Static site, no build step** — `index.html` is self-contained.
- **Deployment:** Vercel, import this repo as a static site (no framework,
  no build command, output directory = repo root).
- **Files:** `index.html`, `favicon.ico`, `favicon.png`,
  `create-token-marked.png`, `_headers` (Cloudflare-specific, kept as-is;
  Vercel ignores it).

No file in this repo has been modified for the move — this is a transfer only.
The Tong cafe management app (tong-cafe) is a separate system and is NOT part
of this repo.
